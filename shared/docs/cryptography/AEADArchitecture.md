# AEAD Architecture

SafeChat360 employs Authenticated Encryption with Associated Data (AEAD) to protect payloads. Specifically, we use AES-256-GCM.

## The Triad of Inputs
Every encryption operation requires three cryptographic inputs:
1. **Plaintext**: The raw message to be encrypted.
2. **MessageKey**: A mathematically unique 32-byte key generated by the Symmetric Ratchet for exactly this payload.
3. **Associated Data (AAD)**: The deterministic, unencrypted `MessageHeader`.

## The Outputs
The AEAD cipher produces two mathematically linked outputs:
1. **Ciphertext**: The encrypted payload.
2. **Authentication Tag**: A 16-byte MAC (Message Authentication Code) that guarantees the ciphertext and the AAD were not tampered with.
